# Changelog — NotifyPro

All notable changes to NotifyPro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] — 2024-01-01

### Added

- Initial release with 30 DocTypes across 10 modules
- Multi-channel notification engine (Email, SMS, WhatsApp, Telegram, Push)
- 6 channel providers with pluggable architecture
- Template management with variable substitution
- Campaign scheduler with audience targeting
- User notification preferences and opt-out support
- Real-time notification routing with priority and fallback
- Analytics dashboard with delivery rate tracking
- Notification Analytics script report with chart
- CAPS capability integration (15 capabilities)
- Full Arabic translation (ar.csv, 270+ strings)
- Seed data for channels, templates, and routing rules
- API v1 endpoints (notifications, channels, templates)
- 7 workspace pages for desk navigation
- Unit and integration tests
- Demo data loader
- CI/CD workflows (ci, linters, release, auto-label, stale)
- GitHub wiki (9 pages)
