# NP Manager — Usage Scenarios
# سيناريوهات استخدام — مدير الإشعارات

## Role Overview

- **Title**: Notification Manager / مدير الإشعارات
- **CAPS Capabilities**: NP_manage_templates, NP_run_campaigns, NP_view_analytics, NP_bulk_send, NP_export_reports
- **Primary DocTypes**: NP Template, NP Campaign, NP Delivery Report
- **Device**: Desktop

## Daily Scenarios (يومي)

### DS-001: Create Notification Template
- **Goal**: Create a new message template for a channel
- **Steps**:
  1. Navigate to Templates workspace → NP Template → New
  2. Set template_name, channel, subject, body with variables
  3. Preview rendered template
  4. Save and enable

### DS-002: Launch Campaign
- **Goal**: Send bulk notifications to a target audience
- **Steps**:
  1. Navigate to Campaigns workspace → NP Campaign → New
  2. Select template, define audience filters
  3. Schedule send time or send immediately
  4. Monitor NP Campaign Result for delivery status

## Weekly Scenarios (أسبوعي)

### WS-001: Review Campaign Performance
- **Goal**: Assess campaign delivery and engagement
- **Steps**:
  1. Navigate to Analytics workspace
  2. Filter by campaign name
  3. Review delivery rate, open rate, click rate
  4. Export report for stakeholders
