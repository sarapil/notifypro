# Getting Started

1. Go to **NP Settings** to configure default channel and queue settings
2. Create a **NP Channel** (e.g., Email) and link a **NP Channel Provider**
3. Create an **NP Template** for your notification content
4. Set up **NP Hook Trigger** to auto-send on document events
5. Monitor delivery in **NP Message** list and **NP Analytics Summary**
