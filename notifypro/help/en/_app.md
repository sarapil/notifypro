# NotifyPro — Unified Notification Center
NotifyPro is a multi-channel notification orchestration hub. It supports Email, SMS, WhatsApp, Telegram, Push notifications, and In-App alerts.

## Key Features
- **Multi-Channel Delivery**: Send via any channel with automatic fallback
- **Smart Routing**: Route messages based on user preferences and rules
- **Campaign Management**: Send bulk notifications with tracking
- **Hook Triggers**: Auto-send notifications on document events
- **Analytics**: Track delivery rates, costs, and engagement
- **Templates**: Jinja-based templates with variable support
