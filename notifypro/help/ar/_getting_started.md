# البدء

1. اذهب إلى **إعدادات NP** لتكوين القناة الافتراضية وإعدادات قائمة الانتظار
2. أنشئ **قناة NP** (مثل البريد الإلكتروني) واربط **مزود قناة NP**
3. أنشئ **قالب NP** لمحتوى الإشعار
4. أعد **مشغل أحداث NP** للإرسال التلقائي عند أحداث المستندات
5. راقب التوصيل في قائمة **رسائل NP** و**ملخص تحليلات NP**
